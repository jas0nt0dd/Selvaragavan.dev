# Certificate Images

Add your certificate images to this folder with these exact filenames. The
certification stack will show the image automatically after it is added.

| Certificate | Filename |
|---|---|
| AWS SimuLearn: Generative AI Practitioner | `aws-simulearn-generative-ai.jpg` |
| Amazon Redshift | `amazon-redshift.jpg` |
| Udemy: Prompt Engineering | `udemy-prompt-engineering.jpg` |
| Amypo: Data Science Workshop | `amypo-data-science-workshop.jpg` |
| Meta OpenEnv Hackathon: Finalist | `meta-openenv-finalist.jpg` |
| LinkedIn Learning: Six Sigma Green Belt | `linkedin-six-sigma-green-belt.jpg` |

Use landscape JPG files where possible. Until an image is added, the stack
shows a built-in certificate placeholder instead.
